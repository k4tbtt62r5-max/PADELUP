# PADELUP

Website der Padel-Ranglisten-App PADELUP (GitHub Pages).

- Startseite: `index.html`
- App (Web-Version, verbunden mit Supabase): `app/index.html`
- Impressum, Datenschutz, Nutzungsbedingungen, Support

Der Schlüssel in `app/index.html` ist der öffentliche anon-Schlüssel von Supabase. Er ist für Apps gedacht; der Schutz der Daten läuft über die Zugriffsregeln (RLS) in der Datenbank. Geheime Schlüssel gehören nie in dieses Repository.
